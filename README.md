# Django CRM

A simple CRM (Customer Relationship Management) web application for managing customer records — built with Django, PostgreSQL, and Bootstrap, and deployed on Render.

**Live demo:** https://django-crm-5dr3.onrender.com/

## About

This project lets a logged-in user add, view, edit, and delete customer records. Each record is timestamped on creation.

## Why Django

This project was built to get hands-on practice with Django as a full-stack Python framework. Along the way, a few of its strengths stood out:

- Batteries-included: the built-in admin panel, authentication system, and ORM made it possible to get CRUD and login functionality working quickly, without wiring up separate libraries for each piece.
- ORM over raw SQL: defining and querying the customer model was straightforward with the ORM, without needing to hand-write SQL for CRUD operations.
- Clear project structure: Django's app layout (models, views, templates, urls) made the codebase easy to navigate and extend as features were added.

## Tech Stack

- **Backend:** Django
- **Database:** PostgreSQL
- **Frontend:** HTML, Bootstrap
- **Deployment:** Render

## Features

- User authentication (login/logout)
- Add, view, edit, and delete customer records
